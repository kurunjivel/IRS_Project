1 Employee Portal Functionalities

The Employee Self-Service Portal empowers team members to independently diagnose their career growth, simulate skill upgrades, parse resumes with NLP, and understand ML-driven promotion drivers.

📊

1. Real-Time Readiness Score

Calculates an objective 0–100 Readiness Score evaluating an employee's fit for their target grade.

  • Multi-Factor Weights: Evaluates Technical Skills (40%), Experience (25%), Performance (20%), and Projects (15%).
  • Grade Transition Visualizer: Displays exact progression path (e.g. G2 Senior Engineer → G3 Principal Engineer).
  • Component Breakdown: Interactive charts detailing individual readiness pillars.
🔮

2. SHAP Promotion Explainability

Uses SHAP (SHapley Additive exPlanations) to transparently reveal machine learning decision drivers.

  • Positive Impact Drivers: Highlights factors boosting promotion probability (e.g., Python expertise, high rating).
  • Growth Areas (Negative Drivers): Identifies specific gaps holding back promotion readiness.
  • Zero Black-Box Transparency: Provides actionable clarity rather than opaque predictions.
🎛️

3. Interactive What-If Simulator

Allows employees to dynamically model future growth scenarios and test hypothetical skill/project improvements.

  • Skill Sliders (Level 1-5): Adjust individual technical competencies in real time.
  • Project & Experience Adders: Model additional leadership roles or added tenure.
  • Instant Readiness Delta: Displays real-time score changes (+12.67 pts) and newly satisfied criteria.
🎯

4. Requirement & Skill Gap Analysis

Performs rigorous side-by-side gap analysis against standardized target grade requirement benchmarks.

  • Categorized Audit: Audits Technical Skills, Industry Certifications, Experience, & Projects.
  • Deficit Highlights: Clearly flags missing level requirements (e.g., Current Level 3 vs Required Level 4).
📄

5. AI Resume / CV Profile Extraction

Natural Language Processing engine that parses uploaded resumes to automatically extract updated skills and achievements.

  • Multi-Format Support: Parses PDF, DOCX, and TXT resume files.
  • Candidate Explicit Confirmation: Presents extracted items for explicit user check-off before database update.
🛡️

6. Career Stability Indicators

Evaluates retention signals and flight-risk indicators in a non-alarming, growth-oriented format.

  • Growth Opportunities: Frames retention signals as actionable growth recommendations.
  • Data Audit: Provides complete data quality report.

3 System Architecture & Technical Stack

System Architecture Overview

The IRS platform is built on a clean, decoupled service architecture. The FastAPI backend handles machine learning inference, recommendation orchestration, and database persistence, while the React 18 + Vite frontend delivers a state-of-the-art UI with glassmorphism aesthetics, dynamic micro-animations, and real-time interaction.

⚡

Backend Architecture

  • Framework: FastAPI (Python 3.13 / 3.14) with Async execution.
  • Authentication: OAuth2 Bearer + JWT Token security with Role-Based Access Control (RBAC).
  • Database Layer: MySQL pooled connections with in-memory fallback for high availability.
  • Test Coverage: Verified 307/307 Pytest unit & integration tests.
🤖

Machine Learning & AI Pipeline

  • Supervised Classifiers: Scikit-Learn Random Forest & Gradient Boosting models.
  • Explainable AI: Integrated SHAP Explainer computing exact feature attribution shapley values.
  • NLP Parser: Keyword extraction & regex heuristics for CV parsing.
  • Simulation Engine: Dynamic vector recalculation engine for What-If projections.
🎨

Frontend Architecture

  • Core Stack: React 18, Vite, Tailwind CSS, Lucide Icons.
  • Data Transport: Axios interceptors handling automatic authorization header injection and response unwrapping.
  • Design System: Dark mode aesthetic with custom glassmorphism, responsive grid cards, and smooth scrolling.
